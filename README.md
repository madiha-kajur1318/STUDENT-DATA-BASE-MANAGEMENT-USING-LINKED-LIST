STUDENT-DATA-BASE-MANAGEMENT-USING-LINKED-LIST

 Overview

This project is a menu-driven **Student Record Management System** developed in **C** using a **Singly Linked List**. It demonstrates the implementation of core Data Structures concepts, dynamic memory allocation, file handling, and CRUD operations for managing student records efficiently.

The application allows users to add, modify, delete, display, sort, reverse, and save student records through an interactive console interface.

Features :

- Add new student records
- Display all student records
- Modify records by Roll Number, Name, or Marks
- Delete records by Roll Number or Name
- Sort records by Name or Marks
- Display records in reverse order
- Save records to a file
- Delete all records
- Menu-driven console application

 Technologies Used :

- C Programming
- Data Structures
- Singly Linked List
- Dynamic Memory Allocation
- File Handling
- Structures
- Pointers
- String Manipulation
